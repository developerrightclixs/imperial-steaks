## 6. How to replace an image

1. Save the approved file into `assets/images/`.
2. If the extension changes (e.g. `.svg` placeholder → `.jpg`), update the `src`
   in the pages listed above, and the `width`/`height` attributes to the new
   file's intrinsic size. Everything else on the `<img>` stays. Keeping the same
   filename and pixel size means no markup change at all — that is how the hero
   chicken frame was swapped on 16 Oct.
3. Match the listed **aspect ratio**. Cropping is handled by `object-fit: cover`,
   so an exact pixel match is not required — but a wrong ratio will over-crop.
4. Update the `alt` text if the subject changes.
5. Copy the file into `wp-theme/imperial-steaks/assets/images/` as well, then
   re-run `python tools/build-theme-templates.py` and rebuild the zip.
6. Flip the Status column here.

**Filename is the configuration.** No JSON manifest, no build step for the
static prototype: drop the file in and reload.

### Recommended export specs

| Slot type | Aspect | Export at | Format | Target weight |
|---|---|---|---|---|
| Beef / chicken split | 16:9 | 1760 × 990 | WebP, or JPG q80 | < 250 KB |
| Product / category | 3:2 | 1800 × 1200 | WebP, or JPG q80 | < 250 KB |
| Box photograph | 3:2 | 1800 × 1200 | WebP, or JPG q80 | < 250 KB |
| Badges / seals | any | 400 px wide | PNG-24 with alpha, or SVG | < 40 KB |

## 7. Regenerating the vector artwork

The logos, the box mockup and the product placeholders are generated, not drawn
by hand, so they can be re-cut at any size or in any palette. The generators and
their instructions are in `tools/brand-assets/`. They only need re-running if the
brand colours or the wordmark change.
